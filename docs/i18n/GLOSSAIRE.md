# Glossaire de traduction de Halcyon

Référence : le français (fr-FR). Repli : l'anglais (en-US). Ce glossaire fixe les termes
récurrents pour que chaque langue reste cohérente d'un écran à l'autre. Un nouveau
traducteur commence par ici.

## Règles générales

- **Ton** : direct, sobre, chaleureux sans familiarité. Pas d'exclamations, pas de jargon
  inutile. Phrases courtes : l'interface est dense.
- **Adresse à l'utilisateur** : fr « vous » · en impératif neutre · de « Sie » · es « tú » ·
  it « tu » · pt-PT forme de politesse sans pronom (« Selecione », « Pode… »).
- **Majuscules** : seule la première lettre d'un libellé est en majuscule (« Ajouter un
  jeu », « Add a game »), sauf noms propres. L'allemand garde ses majuscules nominales.
- **Ne jamais traduire** : Halcyon, Steam, Epic Games, GOG, Heroic, Legendary, Minecraft,
  Modrinth, CurseForge, Fabric, Quilt, Forge, NeoForge, RetroAchievements, SteamGridDB,
  Nexus Mods, Sunshine, Moonlight, MangoHud, PresentMon, RTSS, Proton, Wine, umu, Flatpak,
  AppImage, Big Picture (nom du mode), Java, Microsoft, Xbox, PlayStation, Nintendo, les
  noms de jeux et tout contenu venant des boutiques.
- **Variables** : `{name}`, `{n}`, `{}`… se recopient telles quelles ; leur ordre peut
  changer. `{{rom}}` s'écrit avec les accolades doublées (texte littéral `{rom}`).
- **Pluriels** : chaque texte au pluriel a deux formes (singulier, pluriel) dans toutes les
  langues livrées. Ne jamais écrire « (s) ».
- **Typographie** : fr — espace insécable avant « : ; ? ! » et guillemets « » ; en — "…" ;
  de — „…“ ; es — «…» ; it — «…» ; pt-PT — «…». Points de suspension : « … ».
- **Nombres et unités** : séparateurs fournis par le code (`{n}`), ne pas les écrire à la
  main. Unités : fr/es/it/pt « Go, Mo, Ko, o » (pt « GB, MB, KB, B »), en/de « GB, MB,
  KB, B ». « Mio/s, Kio/s » : en/de « MiB/s, KiB/s ».
- **Raccourcis clavier** : « Ctrl », « Alt », « Maj/Shift » restent tels qu'affichés par
  le système ; l'allemand peut écrire « Strg » dans les textes explicatifs.

## Mots-clés de recherche

Les textes de contexte `keywords` (recherche des paramètres et du lancement rapide) sont
des listes de mots séparés par des espaces, sans accents ni ponctuation : synonymes que
l'utilisateur pourrait taper dans sa langue. Les mots-clés français restent toujours
reconnus en plus.

La syntaxe de recherche de la bibliothèque (`installé:oui`, `source:steam`…) accepte les
mots-clés de toutes les langues livrées (voir `crates/halcyon-core/src/search.rs`) : l'aide
affichée cite ceux de la langue courante.
