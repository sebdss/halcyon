Confidentialité

Ce site

  • Aucun cookie, aucune mesure d'audience, aucun outil publicitaire ni traceur.
  • Polices, images et vidéo sont servies par le site lui-même : aucune requête vers un service tiers à l'affichage. Le film n'est téléchargé que si vous le lancez.
  • Une seule exception : la section Téléchargement interroge l'API publique de GitHub (api.github.com) depuis votre navigateur pour afficher la dernière version et ses fichiers. GitHub reçoit alors les informations techniques de toute requête web (adresse IP, navigateur). Le résultat est gardé dix minutes dans le stockage de session de votre navigateur, puis oublié.
  • L'hébergeur (GitHub Pages) peut conserver des journaux techniques de connexion. Voir la déclaration de confidentialité de GitHub.

Le launcher

  • Halcyon ne demande aucun compte et fonctionne hors ligne. Vos bibliothèques, temps de jeu et réglages restent sur votre ordinateur.
  • Les fonctions en ligne (visuels, métadonnées, succès, mises à jour) sont signalées dans l'application et peuvent être désactivées. Elles contactent directement les services concernés (Steam, RetroAchievements, Modrinth, GitHub…).
  • Les clés d'API que vous saisissez sont rangées dans un coffre local : chiffré par Windows (DPAPI) ou réservé à votre compte sous Linux.
  • Les mesures de performances restent sur votre ordinateur.

Détails techniques : dépôt de Halcyon. Questions : tickets GitHub.
